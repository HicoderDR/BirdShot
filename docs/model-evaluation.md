# BirdShot 模型实验计划

## 约束

- 所有推理必须在浏览器或 native App 进程内完成，画面和音频不上传。
- 第一目标设备为近三年的中端 Android；Safari/iOS 作为兼容目标。
- 网页阶段使用 PWA，生产移动端使用 Capacitor，不使用只支持桌面的 Electron。

## 候选模型

| 能力 | 第一轮模型 | 用途 | 限制与许可证 |
| --- | --- | --- | --- |
| 鸟目标检测 | COCO-SSD Lite MobileNet v2 | 验证相机、框选、自动拍照和端侧性能 | Apache-2.0；只能输出 `bird`，小目标能力有限 |
| 鸟目标检测 | YOLO nano 自训练模型（ONNX） | 替换 COCO-SSD，提高小鸟、密集目标与遮挡场景召回 | 需单独确认所选实现和权重的商业许可证 |
| 多目标追踪 | 当前 IoU tracker / ByteTrack | 当前实现验证 UX，ByteTrack 用于生产稳定 ID | ByteTrack 为 MIT；追踪本身不判断物种 |
| 视觉物种分类 | MobileNetV3 / EfficientNet-Lite（自训练） | 裁剪检测框后做二阶段物种分类 | 应用地区物种子集比全球分类更适合手机端 |
| 鸟声分类 | BirdNET TFJS | 3 秒窗口、约 48 kHz、本地实时分类和中文标签 | 官方网页代码 MIT，模型 CC BY-SA 4.0；发布前复核署名与衍生条款 |

BirdNET 官方浏览器参考实现：
<https://github.com/birdnet-team/real-time-pwa>

## 验收指标

在至少一台中端 Android 和一台 iPhone 上记录：

| 指标 | 基线门槛 |
| --- | --- |
| 视觉端到端延迟 p95 | 小于 250 ms |
| 持续视觉速度 | 大于 5 FPS |
| 单次音频窗推理 | 小于 1.5 秒 |
| 30 分钟运行内存 | 无持续增长 |
| 目标 ID 稳定性 | 短暂遮挡 0.5 秒后保持 ID |
| 自动拍照误触发 | 非鸟场景每 10 分钟少于 1 次 |

准确率不能只使用网络图片评估。测试集需要包含远距离小目标、逆光、枝叶遮挡、多鸟交叉、风声、人声、车辆声和多种鸟同时鸣叫。

## UX 规则

- 画面中每只鸟使用固定颜色、编号和独立置信度；列表与框使用同一编号。
- 只有连续命中三帧的目标触发自动拍照，并设置全局冷却时间。
- 声音结果使用可叠放 toast；同物种短时间内合并计数，不抢占相机操作。
- 多种声音并发时最多展示前三项，其余归入“更多候选”；低置信度使用“可能是”，不能显示为确定结论。
- 视觉与声音在时间和地理先验上可以互相加权，但 UI 必须标明“综合判断”，不能把两个弱信号伪装成高置信结果。
