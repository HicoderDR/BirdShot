# 连拍审阅模式（0.4.0）

审阅按**原始连拍组**组织，不按裁剪质量总榜翻页。高层拍摄日期、来源文件夹、可信地点仍只是筛选器，不把同日照片重做成一组。旧自动推荐及技术指标保留作为依据，人工选择另存，不修改原片Exif或旧批次结果。

## 组优先浏览

默认显示连拍组卡片，按真实拍摄时间、缺时间时自然文件名顺序排列。组封面可用该组可靠鸟体的代表裁剪；没有可靠鸟体用登记帧的低清全图或明确占位，不把背景冒充鸟。组可保留多张：自动推荐和人工已遴选状态是两回事，查看组不会自动变成“已审”。

进入组后原图完整画面为主，初始请求长边480像素预览，再按显示/缩放需求升960/1920/3840，必要时加载未改写原文件。480不是16:9裁剪，不影响原像素评分。状态根据当前图的实际解码尺寸标记，不把“最大倍率”说成“原文件已加载”。

当前帧的可靠Birder鸟类实例以真实分割轮廓及编号展示，关联裁剪与原图坐标引线联动；非鸟误检不混入主展示，未知实例明确待确认。选择裁剪后最多显示该实例三项分类候选及原概率；主体纹理不当作眼部合焦。技术依据为一句可读说明，原始证据仍留在数据中。

底部胶片条包含**该组全部原始帧**，包括没有检测裁剪的帧；右侧网格是**其他连拍组**，用于跨组跳转。两者不混为一个列表。右侧封面可切换代表裁剪或约480像素全图，手机可收起侧栏。

## 按键、缩放和多选

| 操作 | 行为 |
| --- | --- |
| A / D | 当前组上一张 / 下一张 |
| Q / E | 上一个 / 下一个连拍组 |
| 空格 | 切换当前张保留状态 |
| W / S | 明确保留 / 明确不选当前张 |
| Ctrl + 鼠标滚轮 | 在画布内以指针原图位置为锚缩放 |
| Esc | 退出审阅模式，按退出偏好呈现确认 |

文本输入、选择框、确认对话框、IME组合输入及键盘repeat不触发业务快捷键。边界不循环误跳。普通滚轮不全局劫持，Ctrl缩放只在审阅画布阻止浏览器页面缩放。手机仍可捏合/拖动，主原图长按保存不用于选择或清理。

同一连拍组切帧保留归一化原图关注位置和缩放，帧横竖/尺寸不同时适度钳制；切到其他组重置。清晰度升级不重置当前关注位置。

“多选”按钮或胶片条长按进入多选；现有自动推荐/人工选择直接显示勾选，不生成另一份临时bit串。非多选点击只导航，多选点击同时预览该帧并切勾选；checkbox只改选择，不二次翻转。整组保留/整组不选/保留当前/取消当前、键盘操作使用同一个照片级状态集合，不立即删除任何原片。

进入审阅时及右上退出附近提供边缘暗色mask与键帽帮助；触控可点帮助，不依赖鼠标hover。帮助遮罩不阻止画布操作，尊重减少动画偏好。

## 人工状态与增量照片

选择按稳定原照片身份保存，不按文件排序下标存`01001`。仅用户确实更改选择才记录人工已遴选；之后改回原值仍保留曾修改的审计事实。后台重新检测/排序不覆盖人工决定，自动推荐作为独立基线。

人工已审组后来新增帧，标为新增待审；新帧不会因为旧组已审而自动获得清理授权。重组/拆组按真实照片身份继承，不确定时提示，不复制别组的删除决定。乐观版本冲突或写入失败明确显示，不能假勾选成功。

审阅状态单独存于用户数据目录的版本化文件，桌面库仍兼容schema1；不修改旧job JSON或源Exif。未来未知版本拒写，不默默重置空库。卸载不清理此状态、照片来源或已完成裁剪。

## 清理已遴选组：只进系统回收站

清理与普通筛片是不同操作：扫描、模型、手动“不选”、卸载均不删除原片。只有用户在清理清单及系统确认中同意后，才对明确登记文件调用系统回收站，不使用永久删除fallback。

默认安全范围：

- 仅完整人工已遴选、没有新增待审帧、源文件稳定的组。
- 主JPEG/PNG中的选中帧保留，其余列定主照片可回收。
- 配对RAW**默认不动**；当次显式勾选“同时处理配对RAW”后才纳入确切登记同stem伙伴，不包含旁文件或目录。
- 零保留组默认跳过；当次额外选择并再次确认才允许整组回收。

退出确认可选仅退出、退出并预览清理或继续审阅；“记住退出选择”只记流程偏好。即使记住清理，也仍显示**这一次的文件清单与确认**，不绕过RAW、零保留、新帧或源变化保护。外部另有“清理已遴选组”和重置退出偏好入口。

清理预览包含保留数、主照片/RAW数、被跳过组及原因。执行前重新核对登记根目录、文件路径、普通文件/无链接逃逸、size/mtime和内容SHA；变化、正在处理、缺文件或不支持回收的项拒绝或跳过，并逐项报告。可取消尚未执行的项，已成功项目不会被当作全批完成或盲重试。

实际操作在Electron主进程调用`shell.trashItem`，成功/失败/准备意图写独立审计；审计失败不会触发自动重复回收。系统还原由操作系统回收站管理，App不承诺所有介质（如网络盘）可恢复；失败绝不改为永久删除。用户应先核对清单和备份。

## 本机权限与验证边界

共享网页可以读取组/人工状态，但默认不能修改决定、改退出偏好或执行回收。桌面审阅写入只通过准确登记的回环iframe → 主renderer最小IPC → 私有后台协议，拒绝任意磁盘路径、远程百科页面和跨站请求。主进程另做路径/身份/内容复核，管理和文件白名单仍保留。

本轮真实回收验证只使用自有临时fixture，并从系统回收站还原、核对字节；不会对私人相机目录执行清理。截图和产物不默认含私人照片。安装包仍为Windows x64未签名，其他系统/真实手机的原生菜单行为需另验。

实际完整桌面包已在独立中文/空格路径、System32-only PATH及隔离用户数据运行公开鸟图：4张/2组（含多鸟和EXIF8竖向），真实模型完成后通过桌面iframe桥使用S/Space保存、Ctrl鼠标滚轮缩放、D保留组内zoom、E跨组重置；人工选择重启保持。一次实际原生回收只移走本测试不选的主JPG，保留该组keeper/配对RAW/其他公开组，系统还原后SHA相同。原生回收测试没有对私人目录执行。

完整0.4当前用户安装器也已在隔离中文路径安装后跑通同样的审阅/系统回收还原流程（81.613秒），并覆盖安装、卸载验证应用文件移除而原图/已填充库及自建哨兵保留。该次安装71.841秒、覆盖72.68秒、卸载62.246秒；只是本机单次测试，不是速度承诺，也不代表其他系统或介质均已验证。

初始空库添加来源后的组结果会自动更新，不需要手动刷新：桌面只按已提交viewRevision通知、250ms合并，处理中的共享页也同源轮询；不重载整页或关闭当前详情/退出确认，不改变当前帧及关注位置。只读工作预览则无桌面写桥，所有保存和清理入口明确禁用。
